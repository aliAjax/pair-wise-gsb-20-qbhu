# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库 —— 支持教师离线补记与管理员在线修改的逐字段协同合并。

## 技术栈

React 19 + Vite + TypeScript + CSS（无后端，服务端/客户端均在浏览器内模拟，数据持久化于 localStorage）

## 本地运行

```bash
npm install
npm run dev          # http://localhost:5106
npm run build        # 类型检查 + 产物构建
npm run test:logic   # 合并/冲突/染色级联/批次的 30 项逻辑断言
```

开发端口：5106

## 业务流程

1. **离线补记（教师）**：点「模拟断网」后修改样本/视野字段、补记视野记录、提交复核批次；改动只写入本机 outbox 与断网快照，字段上显示「本机待同步」。
2. **管理员并发修改**：离线横幅内可用「☁ 云端模拟」让管理员在云端改染色方式 / 观察结构。
3. **逐字段合并**：点「恢复网络并同步」后按字段版本号（baseRev → serverRev）三路合并：
   - 只有教师改过 → 直接快进；
   - 只有管理员改过 → 保留管理员值；
   - 两边改同一字段且值不同 → **管理员字段受保护不被覆盖，离线值另存为冲突，双版本并排保留**，由管理员裁决。
4. **染色方式级联**：任一方修改样本染色方式（stainingRev +1），所有旧版本确认的关联视野记录立即 `invalidated` 退回待复核，从待归档批次摘除，且不计入有效统计；归档批次冻结保留，归档后染色再变会把其中条目标记失效。
5. **复核批次**：教师只能提交批次；**仅管理员且在线**能「确认归档」，归档时再次剔除已失效条目；教师对退回记录可在重新观察后提交复核。
6. **重开页面接着处理**：全部状态（角色、在线状态、outbox、草稿、冲突、批次、日志）自动写入 localStorage。
7. **导出**：一键导出 JSON，含样本、视野记录、批次、冲突双版本、裁决结果与中文冲突说明（conflictSummary）。

## 状态模型

- 视野记录：`pending`（待复核）/ `valid`（已归档有效，唯一计入有效统计）/ `invalidated`（染色变更退回）
- 复核批次：`pending`（待管理员归档）/ `archived`（冻结快照）
- 冲突：`open`（双版本待裁决）/ `resolved`（记录胜出版本与最终值）

## 代码结构

- `src/types.ts` —— 领域类型、离线操作（outbox）与同步报告
- `src/engine.ts` —— 种子数据、逐字段合并（runSync）、染色级联、批次归档、离线投影、统计、导出
- `src/App.tsx` —— 角色/网络切换、编辑界面、批次面板、冲突裁决、云端并发模拟
- `test/engine.test.ts` —— 六类场景的 30 项逻辑断言
