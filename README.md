# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库 —— 支持**教师离线补记**与**管理员在线复核**的协同工作台。

## 技术栈

React + Vite + TypeScript + CSS（localStorage 持久化，无后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 数据串联

```
样本（染色方式 / 版本）── 视野记录（字段级版本）── 复核批次（归档锁定）
```

每条视野记录同时挂在样本和复核批次上；批次卡片实时显示记录数与有效数。

## 核心机制

- **离线优先**：教师离线补记先写入本机 outbox（localStorage 持久化），页面以「待同步」标记预览暂存值；重开页面可继续处理。
- **逐字段合并**：网络恢复后按字段逐个合并。服务端字段未被改动 → 直接采用离线值；双方改了同一字段 → 两版都保留并标出冲突。
- **管理员优先**：管理员改过的字段不会被后到的离线值覆盖；冲突生效值暂定管理员版，由管理员裁决（保留服务端 / 采用离线补记）。
- **染色方式失效**：管理员修改样本染色方式后，该样本所有记录退回「待复核」，退出有效统计；由管理员逐条「复核确认」恢复。
- **复核批次**：仅管理员可确认归档；存在未解决冲突的批次不能归档；归档后记录锁定。
- **导出报告**：Markdown 报告含有效统计口径、记录明细、冲突说明（两版内容、采用版本、处理状态）与本机待同步清单。

## 演示流程

界面顶部「演示流程」面板有分步指引：教师离线改字段 → 管理员改同字段/染色 → 恢复在线看合并与冲突 → 裁决、复核、归档、导出。

## 验证

合并引擎通过 35 项端到端断言（离线暂存、持久化、字段级合并、管理员优先、冲突保留两版、染色失效与统计口径、归档权限、导出内容）。
